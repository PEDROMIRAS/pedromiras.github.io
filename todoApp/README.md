# Todo App

Lista de tareas en React (Vite). Forma parte del [portfolio](../README.md).

Demo: <https://pedromiras.github.io/todoApp/>

## Qué hace

- Añadir, completar y borrar tareas.
- Filtrar entre todas, pendientes y completadas.
- Estadísticas en vivo de cuántas hay y cuántas están hechas.
- Las tareas se guardan en el navegador (`localStorage`), así que siguen ahí al recargar.

Toda la aplicación está en [src/App.jsx](src/App.jsx).

## Uso en local

```bash
npm install
npm run dev     # servidor de desarrollo
npm run build   # versión de producción en dist/
```
